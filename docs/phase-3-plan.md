# Phase 3 — Scale

Started 21 September 2026 on `feature/advanced-tool-experience`.

## Objectives

1. Expand programmatic SEO through genuinely useful calculator collections rather than thin doorway pages.
2. Strengthen localized discovery for German, French, Portuguese, Italian, Japanese and Spanish.
3. Add an embeddable-calculator surface for link acquisition.
4. Improve localized slugs and redirects without breaking existing indexed URLs.
5. Preserve static output, transparent formulas, accessibility, schema validity and internal-link integrity.

## First batch

The first batch introduces four localized collections across all seven active locales:

- Student calculator toolkit
- Home project planning calculators
- Small business metrics calculators
- Loan and savings planning calculators

Each collection has localized metadata, curated tools, internal links and CollectionPage, ItemList and BreadcrumbList structured data. The all-tools directory links to every collection.

## Next batches

- Validate the collection build, schema and mobile layouts.
- Add embed routes and a copyable iframe generator for selected calculators.
- Audit pt/de/fr body-copy completeness and prioritize high-intent human review.
- Design localized-slug redirects and migration checks.
